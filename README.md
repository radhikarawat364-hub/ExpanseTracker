# 💰 Expense Tracker

A beginner-friendly Expense Tracker project developed using Python.

## 📌 About the Project

The Expense Tracker helps users manage their daily expenses.
Users can add, view, edit, delete, and search expenses.
The program also calculates the total amount spent.

## 🚀 Features

- ➕ Add Expense
- 📋 View All Expenses
- 💰 Calculate Total Expenses
- ✏️ Edit Expense
- 🗑️ Delete Expense
- 🔍 Search Expense by Category
- 📅 Add Expense Date
- 🏷️ Add Expense Category

## 🛠️ Technologies Used

- Python
- Python Lists
- Python Dictionaries
- Functions
- Loops
- Conditional Statements

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:
